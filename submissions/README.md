# submissions/

Every file uploaded to the Zindi leaderboard, named by version. Final picks: `submission_v34.csv`
and `submission_v15.csv`. Each rebuilds exactly with `python score.py <version>`.

`submission_const_000.csv` and `submission_const_010.csv` are the two calibration constants.
Public scores for every file are in `analyse.py` and [docs/rounds.md](../docs/rounds.md).
